# Voices38 Definitive Collection

A simple, modern desktop app to browse and check the status of Voices38 game links.

## 📥 How to Download & Run

  1. Go to the **Releases** tab on the right side of this page.
  2. Download the latest `Voices38.exe` and `games.json`.
  3. Put **BOTH** files into the same empty folder on your PC.
  4. Double-click `Voices38.exe` to run the app!

## 🔄 Auto-Updater

When new games are added, simply click the **"⬇ Update List"** button inside the app. It will automatically download the latest game list without you needing to download a new `.exe`.

## 🛠️ Built With

  * Rust
  * eframe / egui (For the UI)
  * ureq & rayon (For fast, multi-threaded link checking)
